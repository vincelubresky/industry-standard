Step 4

Ongoing — Ordering Discipline (Permanent Rules)

Starting Apr 27 · Every week
Order weekly — never in bulk
If supplies run low mid-week, that's a par-level problem to solve — not a reason to double-order next week. One order per week, per location.
$400+ orders require sign-off
Any single order over $400 needs a second set of eyes before it's placed. This eliminates the bulk-buy spikes that pushed Bessemer to 89.9% COGS in a single week.
Track running weekly COGS total
Post the running total somewhere visible. If Birmingham is at $3,400 on Thursday, there is $460 left for the week — not a blank check for a new full order.
Two vendors, split by item — always
Shaver ISP: drink mix, pastas, carrots, beans, grits, oats, cake mixes, spices, cheese sauce.
PFG: flour, sugar, rice, cream of mushroom, bread, pinto beans, everything else.
Verify Shaver pricing quarterly
The ISP renews annually (March–March). Each quarter, spot-check the 23-item switch list and confirm Shaver is still cheaper. Adjust if pricing shifts.

Current actual is $0.76/meal. Full Shaver transition + COGS caps + weekly ordering discipline closes the gap. $48,000 in annual savings at scale.
